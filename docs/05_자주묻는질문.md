# 자주 묻는 질문

개인정보작전실을 쓰다가 궁금한 점을 모았습니다. 화면 이름은 기본 말투인 **작전 말투**로 쓰고, 쉬운 말에서 보이는 이름을 괄호 안에 함께 적었습니다.

---

## 시작하기 전에

### 이 프로그램은 무엇을 하나요?
개인정보가 담긴 업무 문서를 AI에 올리기 전에, 내 컴퓨터 안에서 이름과 연락처 같은 개인정보를 찾아 `[이름-01]` 같은 코드명(가명코드)으로 바꿉니다. AI 작업이 끝난 결과물을 다시 넣으면 코드명을 원래 이름으로 되돌립니다.

### 인터넷으로 내 문서가 나가나요?
나가지 않습니다. 프로그램은 인터넷에 연결하지 않고 내 컴퓨터 안에서만 돌아갑니다. AI에 올리는 일은 사용자가 직접 하고, 그때 올라가는 것은 코드명으로 바뀐 문서뿐입니다.

### 원본 파일이 바뀌나요?
바뀌지 않습니다. 원본은 그대로 두고 항상 새 파일을 만듭니다.

### 어떤 파일을 넣을 수 있나요?
한글(HWP, HWPX), PDF, 엑셀(XLSX)입니다. 파일 여러 개나 폴더를 한꺼번에 끌어다 놓아도 됩니다. 한글 HWP 파일은 결과를 HWPX로 냅니다.

### 스캔한 PDF도 되나요?
글자 없이 그림으로만 된 쪽은 아직 읽지 못합니다(다음 버전에서 지원 예정). 이런 쪽이 있으면 화면 위에 **사각지대**(검사 못 한 영역)로 알려 주고, 그 쪽의 글자는 결과물에 들어가지 않습니다. 문서 속 그림이나 도형 안의 글자도 같습니다.

## 판정하기

### 어떤 개인정보를 찾나요?
| 무엇 | 어떻게 찾나 |
|---|---|
| 주민등록번호, 외국인등록번호, 여권번호, 운전면허번호 | 번호 형식. 뒷자리를 가린 주민등록번호(`900101-1******`)도 찾습니다. |
| 전화번호, 이메일, 계좌번호, 카드번호, 주소, 생년월일 | 번호와 글의 형식. `010)0000-0000`이나 전각 숫자처럼 모양이 달라도 찾습니다. |
| 이름 | 성명 열, `담당자: 홍길동` 같은 이름표, 직위나 역할 옆(`홍길동 주무관`, `담임 홍길동`), 서명 자리(`홍길동 (인)`), 결재란처럼 한 글자씩 띄어 쓴 이름. 제목이 없는 명단도 값 대부분이 이름 모양이면 찾습니다. |
| 소속, 직위, 직급, 나이대 | 참고로 보여 줍니다. 아래 '요주의 구역'을 보세요. |

규칙으로 찾으므로 놓치는 것이 있을 수 있습니다. 작전 개시 전에 문서를 한 번 훑어보세요.

### 대기, 확정, 제외, 참고는 무슨 뜻인가요?
| 표시 | 뜻 |
|---|---|
| ○ 대기 | 프로그램이 찾은 개인정보 후보입니다. 사람이 판정해야 합니다. |
| ● 확정 | 개인정보가 맞다고 판정한 것입니다. 코드명으로 바뀝니다. |
| 제외 | 개인정보가 아니라고 판정한 것입니다(오탐). 그대로 둡니다. |
| ◌ 참고 | 혼자서는 누군지 알 수 없는 값입니다. 아래 '요주의 구역'을 보세요. |

프로그램은 아무것도 스스로 확정하지 않습니다. 모든 후보는 사람이 판정해야 처리됩니다.

### 개인정보가 아닌데 잡힌 것(오탐)은 어떻게 하나요?
그 줄을 골라 **타깃 해제**(오탐 제외)를 누릅니다. 판정 칸의 표시를 두 번 눌러 확정과 제외를 바꿀 수도 있습니다.

### 판정을 잘못했어요. 되돌릴 수 있나요?
그 줄을 골라 **판정 취소**(대기로 되돌리기)를 누르면 다시 대기가 됩니다. 작전 개시 전까지 언제든 바꿀 수 있습니다. 여러 개를 한꺼번에 되돌리려면 표 위의 **제외** 칸을 눌러 제외한 것만 걸러 본 뒤, 표 머리의 체크박스로 모두 고르고 **판정 취소**나 **타깃 확정**(개인정보 확정)을 누르면 됩니다.

### 요주의 구역(참고)은 무엇인가요?
소속, 직위, 직급처럼 그 값 하나로는 누군지 알 수 없는 정보입니다. 기본으로는 지우지 않고 문서에 남깁니다. 같은 줄의 이름을 확정하면 함께 보면 누군지 알 수 있으므로 자동으로 판정 대상으로 올라옵니다. 직접 가리고 싶으면 골라서 **타깃으로 올리기**(가명처리로 올리기)를 누릅니다. 표 아래 접힌 구역을 펼치면 보이고, 그 표의 머리 체크박스로 모두 고를 수 있습니다.

### 같은 이름이 여러 군데 있으면 하나하나 확정해야 하나요?
한 곳을 확정하면 프로그램이 모든 문서에서 같은 값을 다시 찾아 대기 줄로 올려 줍니다. **같은 타깃 묶어 보기**를 켜면 같은 값을 한 줄로 모아 한 번에 판정할 수 있습니다.

### '검토 표'가 어디에 있나요?
왼쪽 메뉴의 **작전 보드**(검토 보드)를 누르면 가운데에 나오는 큰 목록입니다.

## 작전 개시(전처리 실행)

### 판정 진행이 100%인데 작전 개시가 멈췄어요.
작전 개시를 누르면 파일을 내보내기 직전에 확정한 값이 결과물에 남아 있는지 마지막으로 검사합니다. 하나라도 남아 있으면 실명이 AI로 나가지 않도록 멈춥니다. 같은 값을 한 곳은 확정하고 다른 곳은 제외한 경우가 대표적입니다. 멈추면 그 값이 있는 줄(확정한 줄과 제외한 줄 모두)을 표에 모아 보여 줍니다. 개인정보가 맞으면 모두 확정하고, 개인정보가 아닌데 잘못 확정한 것이면(예: '공무원'을 이름으로 확정) 모두 제외한 뒤 다시 개시하면 됩니다. 멈춘 시도는 작전 번호를 쓰지 않습니다.

### 작전 개시를 누르면 무엇이 만들어지나요?
**송출함**(보낼 문서함)에 작전 번호 폴더가 생기고, 그 안에 코드명으로 바뀐 문서와 AI에게 줄 규칙 파일이 들어갑니다. 원본 형식(한글, 엑셀, PDF)의 사본도 함께 만듭니다. PDF는 글자를 실제로 지우고 코드명을 넣습니다(검은 상자로 가리기만 하지 않습니다).

### 송출함과 귀환함 폴더가 어디에 있나요?
실제 폴더 이름은 영어입니다. 화면 이름은 말투에 따라 바뀌지만 폴더 이름은 하나로 정해 두었고, AI에게 주는 규칙에도 이 이름이 들어갑니다.

| 화면 이름 | 실제 폴더 |
|---|---|
| 송출함(보낼 문서함) | 작업 폴더 안의 `to_ai` (기본: `문서\작전실\to_ai`) |
| 귀환함(받은 결과함) | 작업 폴더 안의 `from_ai` (기본: `문서\작전실\from_ai`) |

두 폴더 안에는 작전 번호(`M-20261108-01` 등)마다 폴더가 하나씩 생깁니다. AI에 올릴 파일은 `to_ai\작전 번호\docs` 안에 있습니다.

### 작전 번호는 무엇인가요?
`M-20261108-01`처럼 작전마다 붙는 번호입니다. 결과물을 되돌릴 때 어느 대응표를 쓸지 이 번호로 찾습니다. 작전 개시가 끝나면 큰 글씨로 따로 보여 줍니다.

### 규칙 복사는 무엇을 복사하나요?
AI에게 줄 짧은 지시문입니다. 코드명을 한 글자도 바꾸지 말고 그대로 쓸 것, 코드명이 누군지 추측하지 말 것, 결과 파일 이름 앞에 작전 번호를 붙일 것 같은 내용이 들어 있습니다. AI가 코드명을 그대로 지켜야 나중에 실명으로 되돌릴 수 있습니다. 문서를 올릴 때 AI 채팅창에 붙여 넣으세요. 송출함 폴더에도 같은 규칙 파일이 들어 있습니다.

### 새 파일을 처리하려면 어떻게 하나요?
**추가 투입**(파일 더 넣기)을 누르거나 파일을 창에 끌어다 놓습니다.
- **작전 개시 전:** 지금 작전에 파일이 더해집니다. 한 작전으로 함께 처리되어 같은 사람은 모든 파일에서 같은 코드명을 받습니다.
- **작전 개시 뒤:** 앞의 작전은 비우고, 새로 넣은 파일만으로 새 작전이 시작됩니다. 이미 내보낸 작전과 대응표는 그대로 남습니다.

### 작전 개시를 누르면 얼마나 걸리나요?
문서 양에 따라 몇 초에서 1분쯤 걸립니다. 누르자마자 '작전 수행 중입니다' 창이 뜨고, 끝나면 저절로 닫히며 송출 완료 창이 뜹니다. 그동안 다른 단추는 잠깁니다.

## 되돌리기(귀환, 복원)

### AI 결과물을 실명으로 되돌리려면?
AI가 만든 결과 파일을 **귀환함**(받은 결과함)의 작전 번호 폴더에 넣고, 왼쪽 메뉴 **귀환**(복원)에서 **복원하기**를 누릅니다. 복원본은 복원본 폴더에 새 파일로 저장됩니다.

### 어떤 형식의 결과물을 되돌릴 수 있나요?
글(MD, TXT), 한글(HWPX), 워드(DOCX), 엑셀(XLSX)입니다. PDF 결과물은 아직 되돌리지 못합니다. AI에게 결과를 글이나 워드, 엑셀로 달라고 하세요.

### AI가 코드명을 조금 바꿔 썼어요(`[이름-02]`를 '이름 2'로).
복원 화면에 '모양이 바뀐 가명코드' 목록이 나옵니다. 맞는 것만 골라 다시 복원하면 됩니다.

### 코드명 하나가 누군지 급하게 알고 싶어요.
**귀환**(복원) 화면 위의 **코드명 찾기**(가명코드 찾기) 칸에 `[이름-01]`처럼 적으면 어느 작전의 누구인지 바로 보여 줍니다. 대괄호를 빼거나 `이름-1`처럼 앞의 0을 빼고 적어도 찾습니다.

### 여러 파일을 한 번에 넣으면 코드명 번호는 어떻게 되나요?
한 작전 안에서는 같은 사람이 모든 파일에서 같은 코드명을 받고, 번호는 이어집니다. 작전이 바뀌면 번호는 01부터 다시 시작합니다. 이전 작전의 번호를 이어 쓰고 싶으면 설정에서 **이전 작전 가명코드 이어 쓰기**를 켭니다.

## 금고와 비밀번호

### 대응표는 무엇이고 어디에 있나요?
코드명과 원래 값을 짝지은 표입니다. 금고 폴더의 작전 번호 폴더 안에 `mapping.enc` 파일로 있습니다. 원래 값이 남는 곳은 이 파일 하나뿐이고, 금고 비밀번호로 암호화되어 있습니다.

### 대응표 파일을 직접 열어 볼 수 있나요?
열 수 없습니다. 암호화된 파일이라 메모장 같은 프로그램으로 열면 알아볼 수 없는 글자만 보입니다. 이 프로그램에서 비밀번호로 금고를 열어야만 쓸 수 있습니다. 그래서 되돌리기와 코드명 찾기도 이 프로그램이 있어야 합니다.

### 금고 비밀번호를 잊어버리면요?
되찾을 방법이 없습니다. 비밀번호 없이는 누구도 대응표를 열 수 없게 만든 것이라, 비밀번호를 잊으면 그동안의 결과물을 실명으로 되돌릴 수 없습니다. 비밀번호는 따로 잘 적어 두세요.

### 설정에서 비밀번호를 바꾸면 예전 대응표는 이전 비밀번호인가요?
아닙니다. 바꿀 때 지난 작전의 대응표까지 모두 새 비밀번호로 다시 잠급니다. 바꾸는 도중에 컴퓨터가 꺼져도 다음에 금고를 열 때 마저 정리하므로, 대응표마다 비밀번호가 섞이지 않습니다. 단, 금고 폴더를 따로 복사해 둔 백업은 복사할 때 비밀번호 그대로입니다.

### '이 컴퓨터에서 금고 비밀번호 기억하기'는 안전한가요?
비밀번호를 Windows 자격 증명 관리자에 저장해, 이 컴퓨터의 내 계정으로 켤 때 묻지 않게 합니다. 여러 사람이 같은 계정으로 쓰는 컴퓨터라면 끄는 것이 좋습니다.

### 폴더는 기본으로 어디에 생기나요?
| 폴더 | 기본 위치 |
|---|---|
| 금고 | 문서\작전실금고 |
| 작업 폴더(송출함, 귀환함) | 문서\작전실 |
| 복원본 폴더 | 문서\작전실복원 |

작업 폴더와 복원본 폴더는 설정에서 바꿀 수 있습니다. 금고는 AI에게 주는 폴더와 섞이지 않게 따로 둡니다.

### 대응표 보관 기간은 무엇인가요?
작전마다 처리 기록에 '언제까지 보관할지' 날짜를 적어 두는 값입니다. 프로그램이 그 날짜에 대응표를 자동으로 지우지는 않습니다.

## AI 정찰(AI 탐지, 선택)

### 지금 쓸 수 있나요?
베타(0.9)에는 들어 있지 않습니다. 정식 버전(1.0.0)에서 GitHub 설치 파일판에 선택 설치로 넣을 예정입니다. Microsoft Store판은 AI 모델 없이 규칙으로만 찾습니다. 모델이 설치되어 있지 않으면 설정에 AI 정찰 칸이 나오지 않습니다.

### 꼭 켜야 하나요?
아닙니다. 켜지 않아도 규칙으로 개인정보를 찾습니다. 켜면 규칙이 놓친 것을 더 찾아 줍니다. AI가 찾은 것도 대기로 들어오고, 사람이 판정해야 처리됩니다.

### AI 정찰 단추가 안 보여요.
모델을 설치한 뒤 설정에서 **이름과 주소 정밀 정찰**(schift-ko-pii)을 켜면 나타납니다. 파일을 넣은 뒤, 작전 개시 전에 작전 보드 위쪽 줄 오른쪽 끝에 있습니다(쉬운 말: 정밀 탐지). 누르면 진행률이 보이고, 찾은 것은 표에 더해집니다. 이미 살펴본 파일은 다시 보지 않습니다.

### schift-ko-pii는 왜 이름과 주소만 찾나요?
주민번호, 연락처, 이메일, 계좌번호는 형식이 정해져 있어 규칙이 더 정확하게 찾습니다(주민번호는 검증 숫자까지 확인합니다). 형식이 없는 이름과 주소에서 AI가 실제로 도움이 되므로 그 둘만 맡깁니다. schift-ko-pii는 Schift 사가 공개한 한국어 개인정보 탐지 모델이며, 설치할 때 고르는 선택 항목입니다.
