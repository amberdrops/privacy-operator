# 테스트 문서

**실제 개인정보가 담긴 문서는 절대 넣지 않는다.** 모든 이름, 연락처, 주소는 지어낸 값이다.

## 만들 문서

| 파일 | 형식 | 심어 둘 내용 |
|---|---|---|
| `연수운영계획_샘플.hwpx` | HWPX | 강사 표(강사 열에 이름 3명, 소속, 연락처), 담당자 레이블, 본문 속 강사 이름 반복, '미정' 칸 |
| `만족도조사_샘플.xlsx` | XLSX | 응답자 이름 열, 이메일 열, 주관식 답변 속 간접식별 문장 |
| `강사계약_샘플.pdf` | PDF | 주민등록번호 형식 값, 계좌번호, 주소, 대표번호(오탐 확인용) |

## 정답 목록

각 샘플마다 `<파일명>.answers.json`에 심어 둔 값과 유형, 위치를 적는다. 탐지 테스트는 이 목록을 기준으로 놓친 것과 잘못 잡은 것을 센다.

## 지어낸 값 규칙

- 휴대전화는 `010-0000-0000`부터 `010-0000-0099`처럼 실제로 쓰이지 않을 번호를 쓴다.
- 주민등록번호 형식 값은 월을 `13`처럼 존재하지 않는 값으로 둬서(예: `901301-1000000`) 형식만 맞춘다. 탐지는 날짜 검증에 실패해도 후보로 잡아야 한다.
- 이메일 도메인은 `example.kr`, `example.com`만 쓴다.

## 만드는 방법

샘플은 손으로 고치지 않고 `samples/make_samples.py` 하나로 다시 만들 수 있게 한다(1단계에서 작성). 스크립트 안에 지어낸 값과 정답 목록을 함께 두고, 문서와 `.answers.json`을 같은 값에서 만들어 둘이 어긋나지 않게 한다.

| 형식 | 만드는 도구 | 방법 |
|---|---|---|
| XLSX | openpyxl | 시트 1개에 머리글 행(`응답자`, `이메일`, `소속`, `주관식 의견`)과 응답 행 5개. 숨김 시트 1개와 셀 메모 1개도 넣어 사각지대 검사에 쓴다 |
| PDF | PyMuPDF | 새 문서에 `insert_text(..., fontname="korea")`로 한글 본문을 쓴다(내장 한글 글꼴이라 별도 글꼴 파일이 필요 없다). 문서 속성(작성자)에도 지어낸 이름을 넣는다 |
| HWPX | zipfile + XML | HWPX는 zip 묶음이다. `mimetype`(압축 없이 맨 앞), `version.xml`, `META-INF/container.xml`, `Contents/content.hpf`, `Contents/header.xml`, `Contents/section0.xml`을 만든다. 본문 문단과 표(`hp:tbl`)는 `section0.xml`에 쓴다 |

- HWPX를 스크립트로 만든 뒤에는 **한글에서 열리는지, kordoc이 읽는지** 확인한다. 둘 중 하나라도 안 되면 한글에서 빈 문서를 새로 만들어 같은 내용을 입력하고 `.hwpx`로 저장한 파일을 쓴다. 이때도 값은 스크립트의 지어낸 값을 그대로 옮긴다.
- `연수운영계획_샘플.hwp`는 위 HWPX를 한글에서 `.hwp`로 다시 저장한 것이다. 스크립트로는 만들 수 없다. 정답 목록은 HWPX의 것을 같이 쓴다. **HWPX 내용을 바꿔 다시 만들면 HWP도 한글에서 다시 저장한다.**

### 정답 목록 형식

```json
{
  "file": "연수운영계획_샘플.hwpx",
  "answers": [
    {
      "answer_id": "A01",
      "value": "(지어낸 값)",
      "category": "이름",
      "tier": "확실",
      "location": { "kind": "table", "table": 0, "row": 1, "col": 0, "header": "강사" }
    }
  ],
  "must_not_detect": [
    { "answer_id": "N01", "value": "미정", "reason": "예외 목록" }
  ]
}
```

- `location.kind`는 `paragraph`(쪽, 문단 번호), `table`(표 번호, 행, 열, 열 제목), `cell`(시트, 셀 주소), `metadata`(속성 이름), `comment`(메모 위치) 중 하나다.
- 탐지 테스트가 실패할 때는 `answer_id`와 유형만 출력하고 `value`는 출력하지 않는다. 지어낸 값이라도 원문 값을 찍지 않는 습관을 테스트에서부터 지킨다.
